# Product

## Register

product

## Users

Developers who work across several AI coding assistants and need an ambient, glanceable view of usage limits and active agent state without interrupting their work.

## Product Purpose

Codenotch turns provider quotas and session activity into a compact macOS edge surface. Success means the user can tell which assistant has capacity, which session needs attention, and when a limit resets without opening each provider separately.

## Brand Personality

Native, precise, and unobtrusive. The interface should feel like a considered part of macOS: quiet at rest, immediately legible when engaged, and honest about uncertain provider data.

## Anti-references

Avoid dashboard-like chrome, decorative effects that compete with usage state, invented controls where macOS already has a familiar one, and generic floating overlays that feel detached from the screen edge.

## Design Principles

- Keep the ambient surface out of the way until the user asks for detail.
- Make usage and agent state understandable at a glance.
- Use native macOS behavior and materials where they improve familiarity.
- Preserve spatial continuity between the screen edge, notch, provider ring, and detail card.
- Represent missing or stale data honestly rather than inventing certainty.

## Accessibility & Inclusion

Honor macOS Reduce Motion and Reduce Transparency preferences, preserve keyboard and assistive-technology semantics for settings, and never make color or haptic feedback the only carrier of status.
